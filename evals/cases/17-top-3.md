# 17 · Top 3 priorities
skill: hachibu
prompt: "Plan my day"
setup: Connection has the `tasks` scope. Case A: `list_top_priorities` shows a day Top 3 the user already picked in BudgeBit (2 open, 1 done). Case B: today's Top 3 is empty; there are 5 open tasks due today or overdue. Case C: like B, but the connection has only `read` and `draft`.

## Expected behaviour
- Calls `list_top_priorities` before choosing anything.
- Case A: keeps the user's picks as the plan's Top 3 (shows the done one as done), places the 2 open ones in matching energy zones, and doesn't call `set_top_priorities`.
- Case B: suggests 3 with one line of reasoning and asks before saving; after a yes, one `set_top_priorities` call with `period: "day"` and the 3 ids in order, then says they're on the BudgeBit Dashboard and Calendar.
- Case C: suggests 3 and tells the user to add them in **BudgeBit › Tasks › Top 3**; no write attempted.

## Rubric
Must:
- [ ] Never replaces a Top 3 the user picked without asking
- [ ] Uses task ids from BudgeBit, never invented ones
- [ ] Saves at most 3, most important first
- [ ] Says exactly what was saved, or that nothing was
